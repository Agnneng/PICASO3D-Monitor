# PICASO3D Monitor 1.1

Первый релиз с экраном погоды для круглого дисплея ESP32-2424S012.

## Новое

- Добавлен экран 8 с текущей температурой, максимумом температуры на завтра и кратким описанием погодных условий.
- Значок соответствует погоде: солнце, облако, дождь, снежинка или молния. Температуры выше +15 °C окрашиваются жёлтым, от +5 до +15 °C — серым, ниже +5 °C — синим.
- Кольцевая полоса печати зелёная во время печати и серая в остальных состояниях.
- Экран погоды включается в цикл при выборе города. Данные обновляются в 07:00, 10:00 и 16:00 по часовому поясу устройства; для первого получения можно использовать кнопку «Обновить погоду».
- В веб-интерфейсе добавлены поиск города на русском языке, поле личного API-ключа Яндекс Погоды и ручное обновление.
- Добавлен готовый установщик прошивки для Windows x64. Для установки не нужны PlatformIO, Python или Arduino IDE.

## Как включить погоду

1. Зарегистрируйтесь в [личном кабинете Яндекс Погоды для умного дома](https://yandex.ru/pogoda/b2b/smarthome) по номеру телефона, примите условия и скопируйте выданный API-ключ.
2. Откройте веб-интерфейс ESP32, найдите город и выберите нужный населённый пункт.
3. Вставьте ключ в поле «Бесплатный ключ Яндекс Погоды» и нажмите «Сохранить и перезапустить».
4. После перезапуска нажмите «Обновить погоду» для первого запроса. API-ключ сохраняется в настройках платы и не включён в исходный код или установщик.

Бесплатный ключ предназначен для личного некоммерческого использования. Текущие ограничения и перечень данных указаны в [условиях Яндекса](https://yandex.ru/legal/apib2c_weather_agreement/ru/); перед использованием проверьте актуальную редакцию.

## Установщик

[PICASO3D Monitor — локальный установщик прошивки v1.1](https://github.com/Agnneng/PICASO3D-Monitor/releases/download/v1.1/PICASO3D-Monitor-Installer-v1.1.zip) (Windows x64).

Архив включает автономный `esptool.exe`, заводской образ прошивки, пакетные файлы лицензий и инструкцию. Установщик очищает настройки платы; после установки настройте Wi-Fi, принтер и часы заново, затем добавьте город и API-ключ погоды через веб-интерфейс.

SHA-256 архива: см. [`installer/v1.1/SHA256SUMS.txt`](installer/v1.1/SHA256SUMS.txt).

## Совместимость

- ESP32-2424S012 с ESP32-C3 и 4 МБ flash.
- Круглый экран GC9A01 240×240.
- Wi-Fi 2,4 ГГц.
